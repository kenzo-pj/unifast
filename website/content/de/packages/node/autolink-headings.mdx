## Signatur

```ts
function autolinkHeadings(options?: AutolinkHeadingsOptions): UnifastPlugin
```

## Parameter

### options?

Konfiguration für das Verhalten der Überschriften-Links

| Eigenschaft | Typ | Standard | Beschreibung |
|----------|------|---------|-------------|
| `behavior` | `"prepend" \| "append" \| "wrap"` | `"prepend"` | Position des Anker-Links relativ zum Überschrifteninhalt |

## Verwendung

```ts
import { compile, autolinkHeadings } from "@unifast/node";

const md = `# Introduction

## Getting Started

### Installation`;

const result = compile(md, {
  plugins: [
    autolinkHeadings({
      behavior: "prepend", // "prepend" | "append" | "wrap"
    }),
  ],
});
```
