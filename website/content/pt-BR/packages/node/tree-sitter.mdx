---
title: "treeSitter()"
description: "Cria um plugin Tree-sitter que habilita syntax highlighting para code blocks fenced usando a biblioteca de parsing Tree-sitter."
---

```ts
import { treeSitter } from "@unifast/node";
```

## Assinatura

```ts
function treeSitter(options?: TreeSitterPluginOptions): UnifastPlugin
```

## Parâmetros

### options?

Configuração da engine de highlighting

| Propriedade | Tipo | Padrão | Descrição |
|----------|------|---------|-------------|
| `engine` | `"none" \| "treeSitter"` | `"treeSitter"` | "treeSitter" usa o highlighter Tree-sitter; "none" desabilita o highlighting |

## Uso

```ts
import { compile, treeSitter } from "@unifast/node";

const md = `
# Code Example

\`\`\`rust
fn main() {
    println!("Hello, world!");
}
\`\`\`
`;

const result = compile(md, {
  plugins: [
    treeSitter({
      engine: "treeSitter",
    }),
  ],
});

console.log(result.output);
// Code blocks are syntax highlighted with <span> elements and CSS classes
```

## Exemplos

### Habilitar syntax highlighting

```ts
import { compile, treeSitter } from "@unifast/node";

const md = `
\`\`\`typescript
const greeting: string = "Hello";
console.log(greeting);
\`\`\`
`;

const result = compile(md, { plugins: [treeSitter()] });

console.log(result.output);
// <pre><code class="language-typescript">
//   <span class="...">const</span> ...
// </code></pre>
```

### Desabilitar highlighting

```ts
import { compile, treeSitter } from "@unifast/node";

const result = compile(md, {
  plugins: [treeSitter({ engine: "none" })],
});

console.log(result.output);
// Code blocks are rendered without syntax highlighting
```
