Compilador de Markdown/MDX de alta performance com arquitetura no estilo Oxc.

## Funcionalidades

- **Rápido** - Core em Rust com parsing zero-copy
- **Completo** - CommonMark, GFM, frontmatter, MDX
- **Seguro** - Sanitização de HTML integrada
- **Portátil** - Node.js (N-API), WASM, CLI
