---
title: "highlight()"
description: "Membuat plugin syntax highlighting highlight.js yang melakukan highlight pada code block fenced melalui transform HAST menggunakan lowlight."
---

```ts
import { highlight } from "@unifast/highlight";
```

## Signature

```ts
function highlight(): UnifastPlugin
```

## Parameter

Tidak ada.

## Penggunaan

```ts
import { compile } from "@unifast/node";
import { highlight } from "@unifast/highlight";

const md = `
\`\`\`typescript
const greeting: string = "Hello";
console.log(greeting);
\`\`\`
`;

const result = compile(md, {
  plugins: [highlight()],
});

console.log(result.output);
// <pre><code class="language-typescript hljs">
//   <span class="hljs-keyword">const</span> ...
// </code></pre>
```

## Contoh

### Dengan banyak bahasa

```ts
import { compile } from "@unifast/node";
import { highlight } from "@unifast/highlight";

const md = `
\`\`\`python
def hello():
    print("Hello, world!")
\`\`\`

\`\`\`css
.container {
  display: flex;
}
\`\`\`
`;

const result = compile(md, { plugins: [highlight()] });
// Both code blocks are highlighted with appropriate highlight.js classes
```

### Dengan plugin lain

```ts
import { compile, gfm, frontmatter } from "@unifast/node";
import { highlight } from "@unifast/highlight";

const result = compile(source, {
  plugins: [gfm(), frontmatter(), highlight()],
});
```
