---
title: "treeSitter()"
description: "Membuat plugin Tree-sitter yang mengaktifkan syntax highlighting untuk fenced code block menggunakan library parsing Tree-sitter."
---

```ts
import { treeSitter } from "@unifast/node";
```

## Signature

```ts
function treeSitter(options?: TreeSitterPluginOptions): UnifastPlugin
```

## Parameter

### options?

Konfigurasi engine highlighting

| Properti | Tipe | Default | Deskripsi |
|----------|------|---------|-------------|
| `engine` | `"none" \| "treeSitter"` | `"treeSitter"` | "treeSitter" menggunakan highlighter Tree-sitter; "none" menonaktifkan highlighting |

## Penggunaan

```ts
import { compile, treeSitter } from "@unifast/node";

const md = `
# Code Example

\`\`\`rust
fn main() {
    println!("Hello, world!");
}
\`\`\`
`;

const result = compile(md, {
  plugins: [
    treeSitter({
      engine: "treeSitter",
    }),
  ],
});

console.log(result.output);
// Code blocks are syntax highlighted with <span> elements and CSS classes
```

## Contoh

### Mengaktifkan syntax highlighting

```ts
import { compile, treeSitter } from "@unifast/node";

const md = `
\`\`\`typescript
const greeting: string = "Hello";
console.log(greeting);
\`\`\`
`;

const result = compile(md, { plugins: [treeSitter()] });

console.log(result.output);
// <pre><code class="language-typescript">
//   <span class="...">const</span> ...
// </code></pre>
```

### Menonaktifkan highlighting

```ts
import { compile, treeSitter } from "@unifast/node";

const result = compile(md, {
  plugins: [treeSitter({ engine: "none" })],
});

console.log(result.output);
// Code blocks are rendered without syntax highlighting
```
