## İmza

```ts
function gfm(options?: GfmPluginOptions): UnifastPlugin
```

## Parametreler

### options?

Bireysel GFM özellikleri için yapılandırma

| Özellik | Tür | Varsayılan | Açıklama |
|---------|-----|------------|----------|
| `tables` | `boolean` | `true` | \| sözdizimi ile pipe tablolarını etkinleştir |
| `taskList` | `boolean` | `true` | - [x] / - [ ] görev listesi onay kutularını etkinleştir |
| `strikethrough` | `boolean` | `true` | ~~silinmiş~~ üstü çizili sözdizimini etkinleştir |
| `footnotes` | `boolean` | `true` | [^1] dipnot referanslarını ve tanımlarını etkinleştir |
| `autolink` | `boolean` | `true` | Çıplak URL'leri otomatik olarak bağlantıla |

## Kullanım

```ts
import { compile, gfm } from "@unifast/node";

const result = compile(md, {
  plugins: [
    gfm({
      tables: true,
      taskList: true,
      strikethrough: true,
      footnotes: true,
      autolink: true,
    }),
  ],
});
```
