## İmza

```ts
function breaks(): UnifastPlugin
```

## Parametreler

Yok.

## Kullanım

```ts
import { compile, breaks } from "@unifast/node";

const md = `This is line one.
This is line two.
This is line three.`;

const result = compile(md, {
  plugins: [breaks()],
});
// Her satır sonu bir <br> elemanına dönüşür
```
