## İmza

```ts
function autolinkHeadings(options?: AutolinkHeadingsOptions): UnifastPlugin
```

## Parametreler

### options?

Başlık bağlantı davranışı yapılandırması

| Özellik | Tür | Varsayılan | Açıklama |
|---------|-----|------------|----------|
| `behavior` | `"prepend" \| "append" \| "wrap"` | `"prepend"` | Çıpa bağlantısının başlık içeriğine göre nereye yerleştirileceği |

## Kullanım

```ts
import { compile, autolinkHeadings } from "@unifast/node";

const md = `# Introduction

## Getting Started

### Installation`;

const result = compile(md, {
  plugins: [
    autolinkHeadings({
      behavior: "prepend", // "prepend" | "append" | "wrap"
    }),
  ],
});
```
