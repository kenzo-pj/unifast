## シグネチャ

```ts
function externalLinks(options?: ExternalLinksPluginOptions): UnifastPlugin
```

## パラメータ

### options?

外部リンク属性の設定

| プロパティ | 型 | デフォルト | 説明 |
|----------|------|---------|-------------|
| `rel` | `string` | `"nofollow noopener noreferrer"` | 外部リンクの rel 属性に設定する値 |
| `target` | `string` | — | target 属性に設定する値 (例: "\_blank") |

## 使い方

```ts
import { compile, externalLinks } from "@unifast/node";

const result = compile(md, {
  plugins: [
    externalLinks({
      rel: "nofollow noopener noreferrer",
      target: "_blank",
    }),
  ],
});
```
