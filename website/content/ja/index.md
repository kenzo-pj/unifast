Oxc スタイルのアーキテクチャを採用した高性能な Markdown/MDX コンパイラです。

## 特徴

- **高速** - ゼロコピーパースを備えた Rust コア
- **完全** - CommonMark、GFM、frontmatter、MDX に対応
- **安全** - HTML サニタイズ機能を標準搭載
- **ポータブル** - Node.js (N-API)、WASM、CLI に対応
