## 시그니처

```ts
function cjk(): UnifastPlugin
```

## 매개변수

없음.

## 사용법

```ts
import { compile, cjk } from "@unifast/node";

const md = `
今日は天気が
とても良いです。
`;

const result = compile(md, { plugins: [cjk()] });
console.log(result.output);
// <p>今日は天気がとても良いです。</p>
```
