Oxc 스타일 아키텍처를 채택한 고성능 Markdown/MDX 컴파일러입니다.

## 특징

- **빠름** - 제로 카피 파싱을 적용한 Rust 코어
- **완전함** - CommonMark, GFM, frontmatter, MDX 지원
- **안전함** - HTML 새니타이즈 기본 내장
- **이식성** - Node.js(N-API), WASM, CLI 지원
