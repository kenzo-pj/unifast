Compilateur Markdown/MDX haute performance doté d'une architecture inspirée d'Oxc.

## Fonctionnalités

- **Rapide** - Cœur Rust avec analyse zero-copy
- **Complet** - CommonMark, GFM, frontmatter, MDX
- **Sûr** - Assainissement HTML intégré
- **Portable** - Node.js (N-API), WASM, CLI
