---
title: "compile()"
description: "La fonction de compilation principale. Transforme du Markdown ou du MDX en HTML ou vers d'autres formats de sortie via le compilateur natif Rust."
---

```ts
import { compile } from "@unifast/node";
```

## Signature

```ts
function compile(input: string, options?: CompileOptions): CompileResult
```

## Paramètres

### input

| Propriété | Type | Défaut | Description |
|----------|------|---------|-------------|
| `input` | `string` | — | Chaîne source Markdown ou MDX |

### options?

| Propriété | Type | Défaut | Description |
|----------|------|---------|-------------|
| `options?` | `CompileOptions` | — | Configuration de compilation, y compris les plugins |

## Valeur de retour

| Propriété | Type | Description |
|----------|------|-------------|
| `output` | `string \| object` | Sortie compilée. Chaîne HTML par défaut ; chaîne JSON pour HAST/MDAST. |
| `frontmatter` | `Record<string, unknown>` | Métadonnées frontmatter analysées (objet vide `{}` si aucun) |
| `diagnostics` | `Diagnostic[]` | Tableau de `{ level, message, start?, end? }` |
| `stats` | `{ parseMs, transformMs, emitMs }` | Détail du temps passé (ms) |
| `toc` | `TocEntry[]` | Table des matières extraite (tableau vide `[]` si la TOC est désactivée) |

## Utilisation

```ts
import { compile, gfm, frontmatter, toc, sanitize } from "@unifast/node";

const md = `---
title: My Document
---

# Hello, **world**!

| Column A | Column B |
|----------|----------|
| Cell 1   | Cell 2   |
`;

const result = compile(md, {
  inputKind: "md",       // "md" | "mdx"
  outputKind: "html",    // "html" | "hast" | "mdast" | "mdxJs"
  plugins: [gfm(), frontmatter(), toc({ maxDepth: 3 }), sanitize()],
});

console.log(result.output);
// <h1 id="hello-world">Hello, <strong>world</strong>!</h1>
// <table>...</table>

console.log(result.frontmatter);
// { title: "My Document" }

console.log(result.toc);
// [{ depth: 1, text: "Hello, world!", slug: "hello-world" }]

console.log(result.stats);
// { parseMs: 0.12, transformMs: 0.08, emitMs: 0.05 }
```

## Exemples

### Markdown de base vers HTML

```ts
import { compile } from "@unifast/node";

const result = compile("# Hello, **world**!");

console.log(result.output);
// <h1 id="hello-world">Hello, <strong>world</strong>!</h1>
```

### Entrée MDX

```ts
import { compile } from "@unifast/node";

const mdx = `
import { Alert } from "./components";

# Hello

<Alert type="info">This is MDX!</Alert>
`;

const result = compile(mdx, { inputKind: "mdx" });
```

### Sortie HAST

```ts
import { compile } from "@unifast/node";

const result = compile("# Hello", { outputKind: "hast" });
const hast = JSON.parse(result.output as string);

console.log(hast);
// { type: "root", children: [{ type: "element", tagName: "h1", ... }] }
```

### Sortie MDAST

```ts
import { compile } from "@unifast/node";

const result = compile("# Hello", { outputKind: "mdast" });
const mdast = JSON.parse(result.output as string);

console.log(mdast);
// { type: "root", children: [{ type: "heading", depth: 1, ... }] }
```

### Sortie MDX JS

```ts
import { compile } from "@unifast/node";

const result = compile(mdxSource, {
  inputKind: "mdx",
  outputKind: "mdxJs",
});

console.log(result.output);
// JavaScript module string with MDX compiled to JSX
```
