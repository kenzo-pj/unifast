
## Signature

```ts
function autolinkHeadings(options?: AutolinkHeadingsOptions): UnifastPlugin
```

## Paramètres

### options?

Configuration du comportement des liens de titres

| Propriété | Type | Défaut | Description |
|----------|------|---------|-------------|
| `behavior` | `"prepend" \| "append" \| "wrap"` | `"prepend"` | Emplacement du lien d'ancrage par rapport au contenu du titre |

## Utilisation

```ts
import { compile, autolinkHeadings } from "@unifast/node";

const md = `# Introduction

## Getting Started

### Installation`;

const result = compile(md, {
  plugins: [
    autolinkHeadings({
      behavior: "prepend", // "prepend" | "append" | "wrap"
    }),
  ],
});
```
