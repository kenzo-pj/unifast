---
title: "compile()"
description: "La función principal de compilación. Transforma Markdown o MDX en HTML u otros formatos de salida usando el compilador nativo en Rust."
---

```ts
import { compile } from "@unifast/node";
```

## Firma

```ts
function compile(input: string, options?: CompileOptions): CompileResult
```

## Parámetros

### input

| Propiedad | Tipo | Por defecto | Descripción |
|----------|------|---------|-------------|
| `input` | `string` | — | Cadena con la fuente Markdown o MDX |

### options?

| Propiedad | Tipo | Por defecto | Descripción |
|----------|------|---------|-------------|
| `options?` | `CompileOptions` | — | Configuración de compilación, incluyendo plugins |

## Retorna

| Propiedad | Tipo | Descripción |
|----------|------|-------------|
| `output` | `string \| object` | Salida compilada. Cadena HTML por defecto; cadena JSON para HAST/MDAST. |
| `frontmatter` | `Record<string, unknown>` | Metadatos del frontmatter parseados (`{}` vacío si no hay) |
| `diagnostics` | `Diagnostic[]` | Array de `{ level, message, start?, end? }` |
| `stats` | `{ parseMs, transformMs, emitMs }` | Desglose de tiempos (ms) |
| `toc` | `TocEntry[]` | Tabla de contenidos extraída (`[]` vacío si TOC está desactivado) |

## Uso

```ts
import { compile, gfm, frontmatter, toc, sanitize } from "@unifast/node";

const md = `---
title: My Document
---

# Hello, **world**!

| Column A | Column B |
|----------|----------|
| Cell 1   | Cell 2   |
`;

const result = compile(md, {
  inputKind: "md",       // "md" | "mdx"
  outputKind: "html",    // "html" | "hast" | "mdast" | "mdxJs"
  plugins: [gfm(), frontmatter(), toc({ maxDepth: 3 }), sanitize()],
});

console.log(result.output);
// <h1 id="hello-world">Hello, <strong>world</strong>!</h1>
// <table>...</table>

console.log(result.frontmatter);
// { title: "My Document" }

console.log(result.toc);
// [{ depth: 1, text: "Hello, world!", slug: "hello-world" }]

console.log(result.stats);
// { parseMs: 0.12, transformMs: 0.08, emitMs: 0.05 }
```

## Ejemplos

### Markdown básico a HTML

```ts
import { compile } from "@unifast/node";

const result = compile("# Hello, **world**!");

console.log(result.output);
// <h1 id="hello-world">Hello, <strong>world</strong>!</h1>
```

### Entrada MDX

```ts
import { compile } from "@unifast/node";

const mdx = `
import { Alert } from "./components";

# Hello

<Alert type="info">This is MDX!</Alert>
`;

const result = compile(mdx, { inputKind: "mdx" });
```

### Salida HAST

```ts
import { compile } from "@unifast/node";

const result = compile("# Hello", { outputKind: "hast" });
const hast = JSON.parse(result.output as string);

console.log(hast);
// { type: "root", children: [{ type: "element", tagName: "h1", ... }] }
```

### Salida MDAST

```ts
import { compile } from "@unifast/node";

const result = compile("# Hello", { outputKind: "mdast" });
const mdast = JSON.parse(result.output as string);

console.log(mdast);
// { type: "root", children: [{ type: "heading", depth: 1, ... }] }
```

### Salida JS de MDX

```ts
import { compile } from "@unifast/node";

const result = compile(mdxSource, {
  inputKind: "mdx",
  outputKind: "mdxJs",
});

console.log(result.output);
// JavaScript module string with MDX compiled to JSX
```
