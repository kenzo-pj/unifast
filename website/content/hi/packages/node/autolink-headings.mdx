
## Signature

```ts
function autolinkHeadings(options?: AutolinkHeadingsOptions): UnifastPlugin
```

## Parameters

### options?

Heading link व्यवहार के लिए Configuration

| Property | Type | Default | विवरण |
|----------|------|---------|-------------|
| `behavior` | `"prepend" \| "append" \| "wrap"` | `"prepend"` | heading content के सापेक्ष anchor link को कहाँ रखा जाए |

## उपयोग

```ts
import { compile, autolinkHeadings } from "@unifast/node";

const md = `# Introduction

## Getting Started

### Installation`;

const result = compile(md, {
  plugins: [
    autolinkHeadings({
      behavior: "prepend", // "prepend" | "append" | "wrap"
    }),
  ],
});
```
