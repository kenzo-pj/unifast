---
title: "highlight()"
description: "Создаёт плагин подсветки синтаксиса на основе highlight.js, который подсвечивает огороженные блоки кода через HAST-преобразования с использованием lowlight."
---

```ts
import { highlight } from "@unifast/highlight";
```

## Сигнатура

```ts
function highlight(): UnifastPlugin
```

## Параметры

Отсутствуют.

## Использование

```ts
import { compile } from "@unifast/node";
import { highlight } from "@unifast/highlight";

const md = `
\`\`\`typescript
const greeting: string = "Hello";
console.log(greeting);
\`\`\`
`;

const result = compile(md, {
  plugins: [highlight()],
});

console.log(result.output);
// <pre><code class="language-typescript hljs">
//   <span class="hljs-keyword">const</span> ...
// </code></pre>
```

## Примеры

### С несколькими языками

```ts
import { compile } from "@unifast/node";
import { highlight } from "@unifast/highlight";

const md = `
\`\`\`python
def hello():
    print("Hello, world!")
\`\`\`

\`\`\`css
.container {
  display: flex;
}
\`\`\`
`;

const result = compile(md, { plugins: [highlight()] });
// Оба блока кода подсвечиваются соответствующими классами highlight.js
```

### С другими плагинами

```ts
import { compile, gfm, frontmatter } from "@unifast/node";
import { highlight } from "@unifast/highlight";

const result = compile(source, {
  plugins: [gfm(), frontmatter(), highlight()],
});
```
