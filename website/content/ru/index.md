Высокопроизводительный компилятор Markdown/MDX с архитектурой в стиле Oxc.

## Возможности

- **Быстрый** — ядро на Rust с парсингом без копирования
- **Полный** — CommonMark, GFM, frontmatter, MDX
- **Безопасный** — встроенная санитизация HTML
- **Переносимый** — Node.js (N-API), WASM, CLI
