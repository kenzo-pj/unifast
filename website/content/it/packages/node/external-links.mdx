## Firma

```ts
function externalLinks(options?: ExternalLinksPluginOptions): UnifastPlugin
```

## Parametri

### options?

Configurazione degli attributi dei link esterni

| Proprietà | Tipo | Predefinito | Descrizione |
|-----------|------|-------------|-------------|
| `rel` | `string` | `"nofollow noopener noreferrer"` | Valore dell'attributo rel sui link esterni |
| `target` | `string` | — | Valore dell'attributo target (ad esempio, "\_blank") |

## Utilizzo

```ts
import { compile, externalLinks } from "@unifast/node";

const result = compile(md, {
  plugins: [
    externalLinks({
      rel: "nofollow noopener noreferrer",
      target: "_blank",
    }),
  ],
});
```
