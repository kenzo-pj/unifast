Compilatore Markdown/MDX ad alte prestazioni con un'architettura in stile Oxc.

## Caratteristiche

- **Veloce** - Core Rust con parsing zero-copy
- **Completo** - CommonMark, GFM, frontmatter, MDX
- **Sicuro** - Sanitizzazione HTML integrata
- **Portabile** - Node.js (N-API), WASM, CLI
